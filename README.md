# My Portfolio

A personal portfolio website built with Next.js and TypeScript.

## What this project is

This site presents:

- who I am
- selected projects
- a contact page with a working contact form

## What visitors can do

- browse featured work
- open project detail pages
- send a message through the contact form

## Tech

- Next.js
- React
- TypeScript

## Contact

Visitors can reach out through the contact page. Messages are delivered by email through the site contact form.
