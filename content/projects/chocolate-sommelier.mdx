This project is an interactive experience that allows users to discover their chocolate preferences through a conversation with an AI bot. Users answer questions about their taste preferences, and the AI bot suggests a personalized chocolate box based on their answers. When the users get their personalized chocolate box, they can see the reason why it matches their taste and they can also change each individual chocolate in the box with another one from the database. The database is based on the real database of Neuhaus Pralines.

The experience combines conversational AI, interactive design, and personalized recommendations. The AI bot is built with OpenRouter and the frontend is built with Next.js. The AI bot uses a custom prompt to understand the user's preferences and generate a personalized chocolate box recommendation by giving tags. These tags are then used to filter the database of chocolates and create a personalized box for the user.

The project is a school project and was developed as a proof of concept for using AI in personalized product recommendations, no collaboration with Neuhaus Pralines.

## Process

The project started with designing the conversational flow and the user interface. The AI bot was trained with a custom prompt to understand user preferences and generate chocolate recommendations. The frontend was built with Next.js, integrating the AI bot and the chocolate database to provide a seamless user experience.

## Challenge

The biggest challenge was ensuring that the AI bot could accurately understand user preferences and generate relevant chocolate recommendations. This required fine-tuning the prompt and testing various scenarios to ensure a smooth and engaging user experience. I had some issues with the AI bot not correctly filtering the database to match tags, but after some research and testing, I was able to get it working properly.
